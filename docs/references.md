# References

## The manual

- **Instruction Manual — Graphics Printer Plus Serial Interface Module** (B&K 2318 + ZI 0054), June 1988, "From serial no. 1129094". Scanned by FrodeM: https://archive.org/details/b-k-2318-zi-0054-instruction-manual
  - The scan has no text layer. Page offsets (PDF page − printed page): pp. 1–8 → +8…+10; ch. 3 (pp. 9–14) → +12; ch. 4 (pp. 15–25) → +14; ch. 5 (pp. 27–47) → +16; p. 49 → PDF 67; appendices pp. 53–64 → +22 (PDF 75–86).
  - Most useful: switches pp. 18–21, socket and cables pp. 22–25, character coding pp. 27–35, control commands pp. 36–48, specifications p. 49, PDI table p. 64.

## Other B&K documents

- BP1535, product data for the 2236 (AO 0404, EIA-574): https://www.bksv.com/media/doc/bp1535.pdf
- B&K 2239 manual: fixed 9600 8N1 XON/XOFF port; lists "AO 0404 → LEMO (for 2318)".
- B&K 1105 and 1213 manuals: B&K-SI lines EXTC/HS/TD/PG; AO 0299 to the ZI 0054.
- Type 3571 product data: "AO 0404 = 9-pole to LEMO (for 2318)".
